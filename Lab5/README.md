# Lab 5 – Event Manager Code Quality and Security

This lab improves the Python event management program using static analysis tools.

## Tools used
- Pylint – code quality and potential errors
- Bandit – security checks
- Flake8 – style and formatting checks

## Files
- `event_manager.py` – updated source code
- `pylint_report_before.txt` and `pylint_report_after.txt`
- `bandit_report_before.txt` and `bandit_report_after.txt`
- `flake8_report_before.txt` and `flake8_report_after.txt`

The reports document the analysis before and after the fixes.
